# Mathlib definitions used in Challenge.lean (the Moser–Tardos theorem)

The statements in `Challenge.lean` define their own notions: the finite product spaces (`IsPMF`,
`pw`, `pE`, `pProb`, copied verbatim from the registered entry on pseudorandom hypergraph
matchings) and the algorithm (`nbr`, `firstViolated`, `step`, `run`, `logAt`, `count`,
`totalCount`, `tableLaw`, `extend`). Otherwise they use only basic notions: finite sums and
products, `Finset.filter`, `Finset.card`, `Finset.univ`, `Finset.range`, `Finset.min'`,
`Disjoint`, `Option.isSome`, `Fin` and the real numbers. Verbatim excerpts at the pinned Mathlib
revision `c55e6e786f49471c72fbddbec5415808896aec1e` (tag `v4.35.0-rc3`, repository
https://github.com/leanprover-community/mathlib4; Apache-2.0):

## Finset.filter

`Mathlib/Data/Finset/Filter.lean`, lines 46–53:

```lean
variable (p : α → Prop) [DecidablePred p] {s t : Finset α}

/-- `Finset.filter p s` is the set of elements of `s` that satisfy `p`. -/
def filter (s : Finset α) : Finset α :=
  ⟨_, s.2.filter p⟩
```

## Finset.sum

`Mathlib/Algebra/BigOperators/Group/Finset/Defs.lean`, lines 68–69 (`Finset.sum` is the additive
version of `Finset.prod`, generated by `to_additive`; `∑ x, f x` is `∑ x ∈ Finset.univ, f x`):

```lean
protected def prod [CommMonoid M] (s : Finset ι) (f : ι → M) : M :=
  (s.1.map f).prod
```

## Fintype and Finset.univ

`Mathlib/Data/Fintype/Defs.lean`, lines 57–61 and 92–93 (`Finset.univ` is the `Finset` of all
elements of a `Fintype`):

```lean
class Fintype (α : Type*) where
  /-- The `Finset` containing all elements of a `Fintype` -/
  elems : Finset α
  /-- A proof that `elems` contains every element of the type -/
  complete : ∀ x : α, x ∈ elems

def univ : Finset α :=
  @Fintype.elems α _
```

## Finset.min'

`Mathlib/Data/Finset/Max.lean`, lines 131–136. `Finset.min'` is generated by `to_dual` from
`Finset.max'`: `s.min' H = s.inf' H id`, the least element of a nonempty finset in a linear order
(here `Fin n`).

```lean
@[to_dual
/-- Given a nonempty finset `s` in a linear order `α`, then `s.min' H` is its minimum, as an
element of `α`, where `H` is a proof of nonemptiness. Without this assumption, use instead `s.min`,
taking values in `WithTop α`. -/]
def max' (s : Finset α) (H : s.Nonempty) : α :=
  sup' s H id
```

## Disjoint

`Mathlib/Order/Disjoint.lean`, lines 48–49 (for finsets, `⊥ = ∅` and `≤` is inclusion, so
`Disjoint s t` means that `s` and `t` have no common element):

```lean
def Disjoint (a b : α) : Prop :=
  ∀ ⦃x⦄, x ≤ a → x ≤ b → x ≤ ⊥
```

Lean core, `src/lean/Init/Data/Option/Basic.lean`, lines 69–71 (toolchain

@[inline, implicit_reducible] def isSome : Option α → Bool
